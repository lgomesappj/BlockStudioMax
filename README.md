# BlockStudioMax

A simple BlockStudioMax Designer for Cloud based deployment.

BlockStudioMax is aimed at developers who need a straightforward, dependable solution.

**Highlights**

- A simple BlockStudioMax Designer for Cloud based deployment

## Key Features

- A simple BlockStudioMax Designer for Cloud based deployment

## Technology Stack

- python
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/BlockStudioMax.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

To configure BlockStudioMax, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
